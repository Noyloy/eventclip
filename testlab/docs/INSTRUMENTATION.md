Assert original clip audio present from ALL clips, marked/unmarked, and absent only in photo-only segments. One original bus + one music bus; no overlapping sources. Expected mix = 0.5 * (original + music * duckEnvelope * endFade). Original pre-mix relative unity; absolute output reduced by common 0.5. Verify preview same gain/envelopes as export, human listening notes for marked and unmarked speech, boundary continuity. Measure decoded sample peak, saturation counts, distortion and AAC overshoot; no blanket true-peak safety claim. Report measured issue before changing fixed gain or source balance.
